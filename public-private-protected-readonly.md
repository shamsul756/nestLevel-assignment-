question 5 : Explain how Access Modifiers (public, private, protected, and readonly) work in TypeScript OOP with examples.


public : public means typescript default behaviour , all people can see this and its also accessible everywhere .inside the class , child classes and outside object.

privat : accessible only inside the class where actually it is created. it cannot use by child class or outside object .

protected : accessible only inside the class and its subclasses. outside object cannot use it . 

readonly : allows data to read but never changed after the object is created .
